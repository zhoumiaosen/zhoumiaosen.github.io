# Miaosen Zhou Personal Website

This is a static personal website for PhD applications and research-oriented job applications.

## Local Preview

Open `index.html` directly in a browser, or run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

Push this repository to GitHub and enable Pages from the repository settings. For a user site, use a repository named:

```text
zhoumiaosen.github.io
```

The site does not require Jekyll, Ruby, or a build step.
